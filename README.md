# Dheyn Michael Orlanda - Portfolio

Personal portfolio built with **Vite + React + TypeScript**.

🌐 [Live Demo](https://necookie-portfolio.dheynorlanda.me/)

## Quick Start

```bash
git clone https://github.com/Necookie/Necookie-Portfolio.git
cd Necookie-Portfolio
npm install
npm run dev
```

Visit `http://localhost:5173/`

## Build

```bash
npm run build
```

## Customization

Edit `gitprofile.config.ts` to update your portfolio content.
